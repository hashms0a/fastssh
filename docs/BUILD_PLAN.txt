 FASTSSH
 STAGED BUILD PLAN FOR AN LLM CODING AGENT
 A Tauri v2 (Rust + React/TypeScript) SSH connection manager and terminal
 multiplexer for Ubuntu (GNOME) and Kubuntu (KDE Plasma), shipped as an AppImage.

Assumptions (inputs that were missing; defaults chosen, see Section 2):
  - <PLAN_DIR> means the folder that holds this plan file and the spec
    (fastssh_tauri_v2_agent_specification.md). The project root is
    <PLAN_DIR>/fastssh, a new subfolder. All relative paths below are from
    the project root. Replace <PLAN_DIR> with the real absolute path
    wherever a command uses it.
  - The build machine is any x86_64 desktop running Ubuntu 22.04 or later
    or an official flavour (Kubuntu, Xubuntu...), with a graphical session
    (GNOME or KDE Plasma, Wayland or X11). The plan assumes NO tool is
    preinstalled. Stage 0A detects the desktop, session, GPU and tools and
    records them as the "machine profile" in HANDOFF_STAGE_00, section 2.
    Later stages use that profile.
  - Build machine = test target. There is no separate device.
  - SSH servers for testing come from a local container. Docker is the
    default; rootless Podman also works (Stage 0A, A.8). If the owner chose
    Podman, replace `docker` with `podman` in every command and record this.
  - Legacy EasySSH 1.7.9 files use kebab-case keys ("identity-file",
    "extra-arguments") and store "port" as a STRING. This was observed on a
    real EasySSH install. FastSSH reads both spellings and writes the legacy
    spelling.
  - The release AppImage must be built against Ubuntu 22.04's glibc (2.35)
    so it runs on 22.04 and later. If the build machine is 22.04, build on
    the host. Otherwise build inside an Ubuntu 22.04 container (Stage 12).
  - The agent drives the UI with WebdriverIO + tauri-driver + WebKitWebDriver.
    The owner approves installing these in Stage 0A.

================================================================================
 1. PRODUCT SUMMARY
================================================================================

FastSSH is a desktop SSH connection manager. It rebuilds EasySSH 1.7.9 from
scratch. The main window has a header bar, a left sidebar and a right
workspace. The header bar holds New Connection, Local Shell, Bookmarks, a
filter field and a menu. The sidebar lists Hosts (grouped, collapsible) or
Shared Accounts. In the workspace, each selected host shows its own notebook
of terminal tabs, or a landing card if it has no tabs. FastSSH drives the
system's /usr/bin/ssh inside a PTY. It does not implement SSH itself.

Core requirements (all MUST be implemented):
  R1  Host library: add, edit, duplicate and remove hosts. Name, group, host,
      port, user, password, identity file, account link, color, font,
      tunnels, extra args and ssh_config block. Names are unique, and spaces
      become "-". Errors appear inline ("Name is already taken").
  R2  Shared Accounts: add, edit, duplicate and remove. Editing an account
      updates username/password/identity_file of every host linked to it.
      Renaming it updates the links. Deleting it asks before unlinking.
  R3  Bookmarks popover: search, add, run and delete shell command bookmarks.
      Run writes "<command>\n" into the active terminal.
  R4  Persistence: hosts.json, accounts.json and bookmarks.json live in
      hostsFolder (default ~/.config/fastssh). settings.json lives in
      ~/.config/fastssh. Writes are atomic with mode 0600. A corrupt file is
      kept, renamed and reported. It never crashes the app or gets
      overwritten.
  R5  One-click import from ~/.config/easyssh (legacy kebab-case keys, port
      as a string). Existing names are skipped.
  R6  Optional GPG symmetric encryption of hosts/accounts/bookmarks
      (*.json.gpg). The passphrase goes over stdin with --passphrase-fd 0 and
      never on argv. A passphrase modal unlocks the files at startup.
  R7  Two-way ~/.ssh/config sync. The first enable makes a backup. Import
      skips wildcards and puts new hosts in group "SSHConfig". Export is
      atomic. The editor has a live ssh_config block.
  R8  A built-in "Localhost" host in group "Local" lives only in memory. It
      opens a local $SHELL in $HOME. The Local Shell header button does the
      same.
  R9  SSH command: standard mode runs
      ssh user@host -p port [-i id] [-L/-R...] [extra]. Sync mode runs
      ssh <name> [extra]. User-controlled values are shell-quoted.
  R10 Host-owned notebooks: tabs belong to a host. Switching hosts never
      unmounts terminals, and the scrollback survives. A host with 0 tabs
      shows ConnectionLanding (Connect/Edit/Remove). Connect works from the
      button, the "+" tab button and a double-click in the sidebar.
  R11 Prompt heuristics: the password is sent automatically, once, before
      login. A fingerprint (yes/no) modal appears. A connection-error modal
      has Retry and Close. Login is detected. A clean logout closes the tab.
  R12 Terminal behaviour: host color/font, falling back to settings;
      scrollback (-1 means 50000); audible bell toggle; clickable web links;
      a right-click context menu; copy, paste and select-all.
  R13 Unread-output dot on tabs and sidebar rows. An open-tab count badge on
      each HostRow. Focusing a tab clears its dot.
  R14 Search toolbar on Ctrl+Shift+F with Next (Ctrl+G), Previous
      (Ctrl+Shift+G), Cyclic and Case-insensitive toggles.
  R15 Alt+C copies the last command's output. Alt+Up scrolls to the start of
      the last command.
  R16 "Show in File Browser" (Ctrl+Shift+E or the context menu) opens
      sftp://user@host:port. It tries xdg-open first, then kioclient exec,
      then dolphin.
  R17 Every shortcut in Section 9 of the spec works. Shortcuts are not
      swallowed by the terminal, and key auto-repeat cannot spawn a burst of
      tabs.
  R18 Preferences modal (General + Appearance) covers every AppSettings
      field. Dark/light theme applies at once.
  R19 Window and session state: window size, maximized state and sidebar
      width persist. When restoreHosts is on, the tabs that were open at quit
      are reopened. Ctrl+Q and the window close button both flush state.
  R20 Every subprocess (ssh, sh, gpg, xdg-open, kioclient, dolphin) runs with
      the sanitized host environment. WEBKIT_DISABLE_DMABUF_RENDERER=1 is set
      at startup unless it is already set.
  R21 A self-contained AppImage FastSSH_<version>_amd64.AppImage. It launches
      and works on Kubuntu (KDE Wayland) and on Ubuntu (GNOME).
  R22 Navigation: the sidebar toggles between Hosts and Accounts. Groups are
      collapsible and their state persists. Hosts are naturally sorted
      (db2 before db10). The header filter narrows the list. WelcomeView
      appears when the library is empty.

Optional enhancements: Stage 11 (prioritized P1/P2/P3). Idea bank: Section 7.


================================================================================
 2. TECHNICAL DECISIONS
================================================================================

Platform:        Linux x86_64 only. Ubuntu 22.04 and later, and its flavours,
                 on GNOME or KDE Plasma, under X11 or Wayland.
Distribution:    AppImage only (bundle.targets = ["appimage"]). Version 1.0.0.
                 Identifier io.github.fastssh.app.
Shell framework: Tauri v2. The Rust backend owns all I/O. The WebKitGTK 4.1
                 webview runs the React UI.
Frontend:        React 19, TypeScript (strict), Vite. Dev port 1420 (as in
                 the spec).
Styling:         Tailwind CSS v4 via @tailwindcss/vite. There is NO
                 tailwind.config.js. Dark mode uses a "dark" class on <html>.
                 Colors are CSS variables (Breeze/Yaru-like) in index.css.
                 Reason: v4 is current. Agents often write v3 setup from
                 memory, and that setup does not work with v4.
State mgmt:      zustand. One store (useAppStore) built from slices in
                 src/store/slices/. Components select narrow slices so that
                 PTY output does not re-render the sidebar.
Terminal:        @xterm/xterm with addon-fit, addon-search and
                 addon-web-links. Default DOM renderer, no WebGL addon,
                 because WebGL in WebKitGTK is unreliable on some
                 GPU/Wayland combinations.
                 Terminal objects live in a registry outside React (see
                 Stage 4).
PTY:             portable-pty. One reader thread and one wait thread per
                 session. Output is decoded to UTF-8 at chunk boundaries in
                 Rust (utf8_chunker.rs) and emitted as Tauri events.
Event naming:    "pty-output-<sessionId>" and "pty-exit-<sessionId>".
                 sessionId is a fresh UUID for each spawn. A tab keeps its
                 tabId across Retry. DEVIATION from the spec's
                 "pty-output-<tabId>": with per-tab names, the exit event of
                 a killed session could close the tab of its retry.
SSH launch:      The PTY runs /bin/sh, and Rust writes " exec ssh ...\n" into
                 it (the spec's pattern). The leading space keeps the line
                 out of shell history. "exec" makes the PTY exit when ssh
                 exits, so the exit code is reliable. DEVIATION: the spec
                 writes plain "ssh".
Sync-mode tunnels: In sync mode, tunnels are exported as LocalForward or
                 RemoteForward lines in the generated block, and
                 extra_arguments are appended to "ssh <name>". Otherwise
                 they would be lost.
Local shell:     $SHELL from the clean environment, or /bin/sh if unset. Its
                 cwd is $HOME. No prompt heuristics run except the exit
                 rule.
Persistence:     JSON files, written by Rust (storage.rs) with
                 tempfile::NamedTempFile in the same dir, then persist()
                 (atomic rename) and fsync of the dir. Files are 0600 and
                 the dir is 0700.
                 hosts.json, accounts.json and bookmarks.json are top-level
                 ARRAYS in the legacy EasySSH shape, plus the keys "id" and
                 "ssh_config". settings.json is an object with
                 "schemaVersion": 1. One schemaVersion in settings.json
                 covers all files.
File shape:      Legacy record keys on disk: name, group, host, port
                 (STRING), username, password, identity-file,
                 extra-arguments, account, color, font, tunnels, plus
                 FastSSH's id and ssh_config. On read, both snake_case and
                 kebab-case are accepted, and port may be a string or a
                 number. Over IPC, Host uses the spec's snake_case with
                 port as a number.
Settings home:   settings.json is ALWAYS in the config dir. It stores
                 hostsFolder, which can point elsewhere for the three data
                 files.
Sandbox paths:   paths.rs honours FASTSSH_CONFIG_DIR (instead of
                 ~/.config/fastssh), FASTSSH_SSH_DIR (instead of ~/.ssh) and
                 FASTSSH_LEGACY_DIR (instead of ~/.config/easyssh). When
                 FASTSSH_SSH_DIR is set, ssh also gets
                 -F <dir>/config -o UserKnownHostsFile=<dir>/known_hosts.
                 Reason: testing must never touch the owner's real files.
Encryption:      gpg (host binary). Flags: --batch --yes --quiet
                 --pinentry-mode loopback --no-symkey-cache
                 --passphrase-fd 0. loopback is required by gpg 2.1+.
                 --no-symkey-cache stops gpg-agent from caching the
                 passphrase, because with a cached one a wrong passphrase
                 would still decrypt. The passphrase is held only in Rust
                 memory (AppState). settings.json is never encrypted.
Keychain:        Secret Service via D-Bus. It is optional (Stage 11, P2).
                 gnome-keyring and kwalletd6 both provide it.
Clipboard:       tauri-plugin-clipboard-manager. navigator.clipboard is
                 unreliable in WebKitGTK.
File dialog:     tauri-plugin-dialog, for picking the identity file. A typed
                 text path always works as the fallback.
Logging:         tauri-plugin-log writes to stdout and to
                 ~/.local/share/io.github.fastssh.app/logs/. Rust uses the
                 "log" macros. JS uses @tauri-apps/plugin-log through
                 src/lib/log.ts. Never use console.log or println!.
Window:          It starts hidden ("visible": false). Rust sets the saved
                 size. The frontend calls show() after the first render.
                 Rust force-shows the window after 5 s as a safety net.
                 minWidth 800 and minHeight 500.
Background:      Nothing runs in the background. On exit, every PTY child
                 is killed (RunEvent::Exit), so no ssh process is orphaned.
Graphics:        main() sets WEBKIT_DISABLE_DMABUF_RENDERER=1 unless it is
                 already set. It does this AFTER the clean environment is
                 captured, so child processes do not inherit it.
Permissions:     Linux has no runtime permission prompts. Tauri
                 capabilities (src-tauri/capabilities/default.json) must list
                 every JS API used. A missing entry fails at runtime with
                 "... not allowed".
UI testing:      Unit: vitest + @testing-library/react with
                 @tauri-apps/api/mocks. E2E: WebdriverIO + tauri-driver +
                 WebKitWebDriver. Every interactive element gets a
                 data-testid.

Known limitations to handle gracefully:
  - gpg missing: the Encrypt toggle is disabled with a tooltip "Install
    gnupg to enable encryption". The library still loads.
  - Wrong passphrase: the modal shows "Wrong passphrase" and stays open. No
    file is written. Cancel quits the app, after a confirm, because without
    the passphrase there is no data.
  - No file manager responds: a toast "Could not open a file browser. Copy
    this address: sftp://..." appears, with a Copy button.
  - ~/.ssh/config unreadable or not writable: a toast with the OS error.
    Sync stays on, but export is skipped until the next successful save.
  - ~/.ssh/config is a symlink (dotfile managers): write to the resolved
    target so the link is never replaced by a file.
  - A corrupt data file: it is renamed to <name>.corrupt-<unix-ts>. The app
    starts with an empty list and a warning banner names the renamed file.
  - The shell prompt is not recognised (zsh "%", fish): auto-login detection
    misses. The session still works, but the tab is not auto-closed on
    "logout". It does close on process exit, which exec guarantees.
  - The host key changed (MITM warning): this is shown as a connection error
    whose message tells the user to run ssh-keygen -R <host>. FastSSH never
    edits known_hosts.
  - libfuse2 missing on the end-user machine: the README documents
    --appimage-extract-and-run.
  - glibc: an AppImage runs only on systems whose glibc is the same as or
    newer than the build system's. The release build therefore targets
    Ubuntu 22.04 (on the host if it is 22.04, otherwise in a container,
    Stage 12).

 4. STAGES OVERVIEW
================================================================================

Stage 0   0A environment audit + sandbox fixtures; 0B project setup, skeleton,
          env_sanitize + DMABUF fix, test harness.                    (R20)
Stage 1   Data model + persistence (Rust storage, settings schema, store,
          load before first frame, debounced save, window size).  (R4, R19a)
Stage 2   App shell: header bar, sidebar (Hosts/Accounts, groups, natural
          sort, filter), WelcomeView, ConnectionLanding, theme.   (R22, R8a)
Stage 3   Editors: ConnectionEditor (+tunnels, live ssh_config block),
          AccountEditor, ErrorRevealer, duplicate/remove, propagation.
                                                                  (R1, R2)
Stage 4   PTY manager + terminal: local shell tabs, HostNotebook, registry,
          no-unmount switching, resize.                  (R8, R10, R12a, R20)
Stage 5   SSH connections + prompt heuristics + fingerprint/error modals,
          tested against the Docker sshd.                         (R9, R11)

use portable_pty::CommandBuilder;
use std::collections::HashMap;
use std::process::Command;
use std::sync::OnceLock;

static CLEAN_ENV: OnceLock<HashMap<String, String>> = OnceLock::new();

const APPIMAGE_VARS: &[&str] = &[
    "APPIMAGE", "APPDIR", "OWD", "ARGV0", "APPIMAGE_UUID", "LD_PRELOAD",
    "GDK_PIXBUF_MODULE_FILE", "GDK_PIXBUF_MODULEDIR", "GSETTINGS_SCHEMA_DIR",
    "GI_TYPELIB_PATH", "GTK_PATH", "GTK_EXE_PREFIX", "GTK_DATA_PREFIX",
    "GTK_IM_MODULE_FILE", "GIO_MODULE_DIR", "GIO_EXTRA_MODULES",
    "QT_PLUGIN_PATH", "PERLLIB", "PYTHONHOME", "PYTHONPATH",
];

/// Pure function so tests never touch the real process environment.
pub fn build_clean_env(vars: impl IntoIterator<Item = (String, String)>) -> HashMap<String, String> {
    let mut env: HashMap<String, String> = vars.into_iter().collect();
    if env.contains_key("APPIMAGE") || env.contains_key("APPDIR") {
        let appdir = env.get("APPDIR").cloned().unwrap_or_default();
        for k in APPIMAGE_VARS { env.remove(*k); }
        match env.remove("ORIGINAL_LD_LIBRARY_PATH") {
            Some(orig) if !orig.is_empty() => { env.insert("LD_LIBRARY_PATH".into(), orig); }
            Some(_) => { env.remove("LD_LIBRARY_PATH"); }
            None => strip_var(&mut env, "LD_LIBRARY_PATH", &appdir),
        }
        // Catch-all: any remaining var whose value points into the mount.
        let keys: Vec<String> = env.keys().cloned().collect();
        for k in keys { strip_var(&mut env, &k, &appdir); }
    }
    env.insert("TERM".into(), "xterm-256color".into());
    env.insert("COLORTERM".into(), "truecolor".into());
    env
}

fn is_appdir_path(seg: &str, appdir: &str) -> bool {
    (!appdir.is_empty() && seg.starts_with(appdir)) || seg.starts_with("/tmp/.mount_")
}

/// Only rewrites values that contain an AppDir path; others are untouched.
fn strip_var(env: &mut HashMap<String, String>, key: &str, appdir: &str) {
    let Some(val) = env.get(key).cloned() else { return };
    if !val.split(':').any(|s| is_appdir_path(s, appdir)) { return; }
    let kept: Vec<&str> = val.split(':').filter(|s| !s.is_empty() && !is_appdir_path(s, appdir)).collect();
    if kept.is_empty() { env.remove(key); } else { env.insert(key.to_string(), kept.join(":")); }
}

pub struct Host {

fn s(o: &serde_json::Map<String, Value>, keys: &[&str]) -> String {
    keys.iter().find_map(|k| o.get(*k)).and_then(|v| match v {
        Value::String(x) => Some(x.clone()),
        Value::Number(n) => Some(n.to_string()),
        _ => None,
    }).unwrap_or_default()
}

/// Accepts legacy (kebab, port string) and FastSSH shapes. Never panics.
pub fn host_from_value(v: &Value, warnings: &mut Vec<String>) -> Option<Host> {
    let o = v.as_object()?;
    let name = s(o, &["name"]).trim().replace(' ', "-");
    if name.is_empty() { warnings.push("Skipped a host with no name".into()); return None; }
    let port_raw = s(o, &["port"]);
    let port = match port_raw.trim().parse::<u16>() {
        Ok(p) if p > 0 => p,
        _ if port_raw.is_empty() => 22,
        _ => { warnings.push(format!("Host \"{name}\": invalid port \"{port_raw}\", using 22")); 22 }
    };
    let id = Some(s(o, &["id"])).filter(|x| !x.is_empty())
        .unwrap_or_else(|| uuid::Uuid::new_v4().to_string());
    Some(Host {
        id, name, port,
        group: s(o, &["group"]), host: s(o, &["host"]),
        username: s(o, &["username"]), password: s(o, &["password"]),
        identity_file: s(o, &["identity_file", "identity-file"]),
        account: s(o, &["account"]), color: s(o, &["color"]), font: s(o, &["font"]),
        tunnels: s(o, &["tunnels"]),

use std::{fs, io::Write, os::unix::fs::PermissionsExt, path::Path};

pub fn atomic_write(path: &Path, bytes: &[u8]) -> std::io::Result<()> {
    let dir = path.parent().ok_or_else(|| std::io::Error::other("no parent dir"))?;
    fs::create_dir_all(dir)?;
    let mut tmp = tempfile::NamedTempFile::new_in(dir)?;   // same FS => atomic rename
    tmp.write_all(bytes)?;
    tmp.as_file().sync_all()?;
    tmp.as_file().set_permissions(fs::Permissions::from_mode(0o600))?;
    tmp.persist(path).map_err(|e| e.error)?;
    fs::File::open(dir)?.sync_all()?;                      // persist the rename
    Ok(())
}

/// Missing => empty; unreadable JSON => renamed aside + warning; never panics.
pub fn read_array(path: &Path, warnings: &mut Vec<String>) -> Vec<serde_json::Value> {
    let Ok(text) = fs::read_to_string(path) else { return vec![] };
    if text.trim().is_empty() { return vec![]; }
    match serde_json::from_str::<serde_json::Value>(&text) {
        Ok(serde_json::Value::Array(a)) => a,
        _ => {
            let ts = std::time::SystemTime::now().duration_since(std::time::UNIX_EPOCH).map(|d| d.as_secs()).unwrap_or(0);
            let aside = path.with_extension(format!("json.corrupt-{ts}"));
            let _ = fs::rename(path, &aside);
            warnings.push(format!("{} could not be read and was moved to {}", path.display(), aside.display()));
            vec![]
        }
    }
}

import type { StateCreator } from 'zustand';
import type { AppSettings } from '../../types/models';
import { DEFAULT_SETTINGS } from '../../types/models';
import { debounce } from '../../lib/debounce';
import { ipc } from '../../lib/ipc';
import { logError } from '../../lib/log';
import type { AppStore } from '../useAppStore';

export interface SettingsSlice {
  settings: AppSettings;
  updateSettings: (patch: Partial<AppSettings>) => void;
  flushSettings: () => Promise<void>;
}

// copyWith semantics: keys whose value is `undefined` are ignored, so a
// partially built patch can't wipe fields. To CLEAR a nullable field, the
// field type must be `T | null` and the patch passes `null` explicitly.
function applyPatch(s: AppSettings, patch: Partial<AppSettings>): AppSettings {
  const clean = Object.fromEntries(Object.entries(patch).filter(([, v]) => v !== undefined));
  return { ...s, ...clean };
}

export const createSettingsSlice: StateCreator<AppStore, [], [], SettingsSlice> = (set, get) => {
  const saver = debounce(() => {
    ipc.saveSettings(get().settings).catch((e) => logError('save_settings failed', e));
  }, 400);
  return {
    settings: DEFAULT_SETTINGS,
    updateSettings: (patch) => { set({ settings: applyPatch(get().settings, patch) }); saver.call(); },
    flushSettings: async () => { saver.cancel(); await ipc.saveSettings(get().settings); },
  };
};

```ts
export interface BlockFields {
  name: string; host: string; port: number; username: string; identityFile: string;
  forwards: string[]; // ["LocalForward 8080 localhost:80", ...]
}
const MANAGED = ['host', 'hostname', 'user', 'port', 'identityfile'] as const;
const FORWARD = /^\s*(localforward|remoteforward)\b/i;
const keyOf = (line: string) => line.trim().split(/[\s=]+/, 1)[0]?.toLowerCase() ?? '';
const quote = (v: string) => (/\s/.test(v) ? `"${v}"` : v);

export function syncBlock(block: string, f: BlockFields): string {
  const managed: Record<string, string> = {
    host: `Host ${f.name}`,
    hostname: f.host ? `    HostName ${f.host}` : '',
    user: f.username ? `    User ${f.username}` : '',
    port: `    Port ${f.port}`,
    identityfile: f.identityFile ? `    IdentityFile ${quote(f.identityFile)}` : '',
  };
  const others = block.split('\n')
    .filter((l) => !(MANAGED as readonly string[]).includes(keyOf(l)) && !FORWARD.test(l))
    .filter((l, i, arr) => !(l.trim() === '' && i === arr.length - 1));
  const head = MANAGED.map((k) => managed[k]).filter(Boolean);
  const fwd = f.forwards.map((x) => `    ${x}`);
  return [...head, ...fwd, ...others].join('\n');
}
```

```rust
use portable_pty::{native_pty_system, ChildKiller, CommandBuilder, MasterPty, PtySize};
use std::{collections::HashMap, io::{Read, Write}, sync::{Arc, Mutex}};
use tauri::{AppHandle, Emitter};
use crate::{env_sanitize, utf8_chunker::Utf8Chunker};

pub enum SpawnSpec { LocalShell, Ssh(String) }

struct Session {
    writer: Box<dyn Write + Send>,
    master: Box<dyn MasterPty + Send>,
    killer: Box<dyn ChildKiller + Send + Sync>,
}
#[derive(Default)]
pub struct PtyManager { sessions: Arc<Mutex<HashMap<String, Session>>> }

impl PtyManager {
    pub fn spawn(&self, app: AppHandle, id: String, spec: SpawnSpec, cols: u16, rows: u16) -> Result<(), String> {
        let pair = native_pty_system()
            .openpty(PtySize { rows: rows.max(1), cols: cols.max(2), pixel_width: 0, pixel_height: 0 })
            .map_err(|e| e.to_string())?;
        let env = env_sanitize::clean_env();
        let shell = match spec {
            SpawnSpec::LocalShell => env.get("SHELL").cloned().unwrap_or_else(|| "/bin/sh".into()),
            SpawnSpec::Ssh(_) => "/bin/sh".into(),
        };
        let mut cmd = CommandBuilder::new(&shell);
        env_sanitize::sanitize_pty_command(&mut cmd);           // env_clear + clean env FIRST
        if let Some(home) = env.get("HOME") { cmd.cwd(home); }
        let mut child = pair.slave.spawn_command(cmd).map_err(|e| e.to_string())?;
        drop(pair.slave);                                       // else reader never sees EOF
        let mut reader = pair.master.try_clone_reader().map_err(|e| e.to_string())?;
        let mut writer = pair.master.take_writer().map_err(|e| e.to_string())?;
        if let SpawnSpec::Ssh(line) = &spec {
            writer.write_all(format!(" exec {line}\n").as_bytes()).map_err(|e| e.to_string())?;
        }
        let killer = child.clone_killer();
        self.sessions.lock().unwrap().insert(id.clone(), Session { writer, master: pair.master, killer });

        let (app_r, id_r) = (app.clone(), id.clone());
        std::thread::spawn(move || {
            let (mut buf, mut dec) = ([0u8; 16384], Utf8Chunker::default());
            loop {
                match reader.read(&mut buf) {
                    Ok(0) | Err(_) => break,                    // EIO on Linux when child exits
                    Ok(n) => { let text = dec.push(&buf[..n]);
                               if !text.is_empty() { let _ = app_r.emit(&format!("pty-output-{id_r}"), text); } }
                }
            }
        });
        let sessions = self.sessions.clone();
        std::thread::spawn(move || {
            let code = child.wait().map(|s| s.exit_code() as i32).unwrap_or(-1);
            sessions.lock().unwrap().remove(&id);
            let _ = app.emit(&format!("pty-exit-{id}"), code);
        });
        Ok(())
    }

    pub fn kill(&self, id: &str) {
        if let Some(mut s) = self.sessions.lock().unwrap().remove(id) { let _ = s.killer.kill(); }
    }
    // write(): lock, writer.write_all + flush. resize(): master.resize(PtySize{..}) with cols>=2, rows>=1.
}
```
Note: the exit event can arrive before the last output chunk has been
emitted, because the threads race. In sessionController, on pty-exit,
wait 50 ms (setTimeout) before closing the tab, so the final output (e.g.
"logout") is processed.

import { Terminal, type ITerminalOptions } from '@xterm/xterm';
import { FitAddon } from '@xterm/addon-fit';
import { SearchAddon } from '@xterm/addon-search';
import '@xterm/xterm/css/xterm.css';

interface Entry { term: Terminal; fit: FitAddon; search: SearchAddon; host: HTMLDivElement; opened: boolean }
const entries = new Map<string, Entry>();

export function createTerminal(tabId: string, opts: ITerminalOptions): Entry {
  const existing = entries.get(tabId);
  if (existing) return existing;                 // idempotent: StrictMode-safe
  const term = new Terminal({ allowProposedApi: true, ...opts });
  const fit = new FitAddon(); const search = new SearchAddon();
  term.loadAddon(fit); term.loadAddon(search);
  const host = document.createElement('div');
  host.className = 'h-full w-full';
  const e = { term, fit, search, host, opened: false };
  entries.set(tabId, e);
  return e;
}

export function attach(tabId: string, container: HTMLElement): void {
  const e = entries.get(tabId);
  if (!e) return;
  if (e.host.parentElement !== container) container.appendChild(e.host);
  if (!e.opened) { e.term.open(e.host); e.opened = true; }
}

export function safeFit(tabId: string): void {
  const e = entries.get(tabId);
  if (!e || !e.opened || e.host.clientWidth === 0 || e.host.clientHeight === 0) return;
  e.fit.fit();
}

export function dispose(tabId: string): void {
  const e = entries.get(tabId);
  if (!e) return;
  entries.delete(tabId);
  e.term.dispose(); e.host.remove();             // term.dispose also disposes loaded addons
}

/** Test helper: plain text of the active buffer (used by e2e via window hook in DEBUG only). */
export function getText(tabId: string): string {
  const b = entries.get(tabId)?.term.buffer.active;
  if (!b) return '';
  const out: string[] = [];
  for (let i = 0; i < b.length; i++) out.push(b.getLine(i)?.translateToString(true) ?? '');
  return out.join('\n').trimEnd();
}
export const getEntry = (tabId: string) => entries.get(tabId);

```ts
export type WatchEvent =
  | { type: 'send-password' } | { type: 'fingerprint'; text: string }
  | { type: 'error'; kind: ErrorKind; line: string } | { type: 'logged-in' } | { type: 'logout' };
export type ErrorKind = 'refused' | 'unreachable' | 'timeout' | 'closed' | 'auth' | 'dns' | 'hostkey';

// eslint-disable-next-line no-control-regex
const ANSI = /\x1b\[[0-9;?]*[ -/]*[@-~]|\x1b\][^\x07\x1b]*(?:\x07|\x1b\\)|\x1b[()][A-Za-z0-9]|\r/g;
const ERRORS: Array<[RegExp, ErrorKind, 'preLogin' | 'always']> = [
  [/Connection refused/i, 'refused', 'preLogin'],
  [/No route to host/i, 'unreachable', 'preLogin'],
  [/Could not resolve hostname/i, 'dns', 'preLogin'],        // extension, recorded
  [/REMOTE HOST IDENTIFICATION HAS CHANGED/i, 'hostkey', 'preLogin'],
  [/Permission denied, please try again\./i, 'auth', 'preLogin'],
  [/Permission denied \(/i, 'auth', 'preLogin'],
  [/Connection timed out|Operation timed out/i, 'timeout', 'always'],
  [/Broken pipe|Connection reset/i, 'closed', 'always'],
  [/Connection closed by/i, 'closed', 'preLogin'],
];
const PROMPT = /(:~[$#]|\]\$|\]#)\s*$/;
const LOGIN_HINT = /(^|\n)(Last login:|Welcome to )/;

export class PromptWatcher {
  private tail = '';
  passwordSent = false;
  loggedIn = false;
  constructor(private readonly hasPassword: boolean) {}

  feed(chunk: string): WatchEvent[] {
    const out: WatchEvent[] = [];
    this.tail = (this.tail + chunk.replace(ANSI, '')).slice(-2048);
    for (const [re, kind, when] of ERRORS) {
      if ((when === 'always' || !this.loggedIn) && re.test(this.tail)) {
        const line = this.tail.split('\n').find((l) => re.test(l)) ?? '';
        out.push({ type: 'error', kind, line: line.trim() });
        this.tail = '';
        return out;                                   // one event per occurrence
      }
    }
    if (!this.loggedIn && /\(yes\/no/i.test(this.tail)) {
      out.push({ type: 'fingerprint', text: this.tail.split('\n').slice(-4).join('\n') });
      this.tail = '';
      return out;
    }
    // Safer than spec: only before login, so a later sudo prompt never gets it.
    if (!this.loggedIn && !this.passwordSent && this.hasPassword && /password:\s*$/i.test(this.tail)) {
      this.passwordSent = true;
      out.push({ type: 'send-password' });
      this.tail = '';
    }
    if (!this.loggedIn && (PROMPT.test(this.tail) || LOGIN_HINT.test(this.tail))) {
      this.loggedIn = true;
      out.push({ type: 'logged-in' });
      this.tail = '';
    }
    if (this.loggedIn && /(^|\n)logout\s*$/.test(this.tail)) { out.push({ type: 'logout' }); this.tail = ''; }
    return out;
  }
}
```

```rust
use std::{process::{Command, Stdio}, time::Duration};
use crate::env_sanitize::sanitize_std_command;

fn run_wait(prog: &str, url: &str, timeout: Duration) -> bool {
    let mut c = Command::new(prog);
    sanitize_std_command(&mut c);
    c.arg(url).stdin(Stdio::null()).stdout(Stdio::null()).stderr(Stdio::null());
    let Ok(mut child) = c.spawn() else { return false };
    let deadline = std::time::Instant::now() + timeout;
    loop {
        match child.try_wait() {
            Ok(Some(st)) => return st.success(),
            Ok(None) if std::time::Instant::now() < deadline => std::thread::sleep(Duration::from_millis(100)),
            _ => { std::thread::spawn(move || { let _ = child.wait(); }); return true; } // still running = launched
        }
    }
}

pub fn open_sftp(url: &str, desktop: &str) -> Result<&'static str, String> {
    if run_wait("xdg-open", url, Duration::from_secs(10)) { return Ok("xdg-open"); }
    if desktop.to_uppercase().contains("KDE") {
        let mut k = Command::new("kioclient"); sanitize_std_command(&mut k);
        if k.args(["exec", url]).status().map(|s| s.success()).unwrap_or(false) { return Ok("kioclient"); }
        let mut d = Command::new("dolphin"); sanitize_std_command(&mut d);
        if let Ok(mut ch) = d.arg(url).spawn() { std::thread::spawn(move || { let _ = ch.wait(); }); return Ok("dolphin"); }
    }
    Err(format!("Could not open a file browser for {url}"))
}
```
Note: call open_sftp from the command with tokio::task::spawn_blocking,
because it can block for up to 10 s. Read XDG_CURRENT_DESKTOP from
env_sanitize::clean_env().

Reference: src-tauri/src/gpg.rs (encrypt)
```rust
use std::{io::Write, process::{Command, Stdio}};
use crate::env_sanitize::sanitize_std_command;

#[derive(Debug)]
pub enum GpgError { NotInstalled, WrongPassphrase, BadPassphraseChars, Failed(String) }

const BASE: &[&str] = &["--batch", "--yes", "--quiet", "--pinentry-mode", "loopback",
                        "--no-symkey-cache", "--passphrase-fd", "0"];

impl GpgRunner {
    fn command(&self) -> Command {
        let mut c = Command::new(&self.program);
        sanitize_std_command(&mut c);                       // env_clear + clean env
        if let Some(h) = &self.gnupg_home { c.env("GNUPGHOME", h); }
        c.args(BASE).stdin(Stdio::piped()).stdout(Stdio::piped()).stderr(Stdio::piped());
        c
    }

    pub fn encrypt(&self, plain: &[u8], pass: &str) -> Result<Vec<u8>, GpgError> {
        if pass.contains(['\n', '\r']) { return Err(GpgError::BadPassphraseChars); }
        let mut c = self.command();
        c.args(["--symmetric", "--armor", "--cipher-algo", "AES256", "--output", "-"]);
        let mut child = c.spawn().map_err(|_| GpgError::NotInstalled)?;
        let mut stdin = child.stdin.take().expect("piped");
        // gpg reads the passphrase line from fd 0, then the data from the rest of stdin.
        let mut input = Vec::with_capacity(pass.len() + 1 + plain.len());
        input.extend_from_slice(pass.as_bytes()); input.push(b'\n'); input.extend_from_slice(plain);
        // Write on another thread: writing all input before reading stdout deadlocks
        // once the stdout pipe buffer (64 KiB) fills.
        let writer = std::thread::spawn(move || { let _ = stdin.write_all(&input); }); // drop closes stdin
        let out = child.wait_with_output().map_err(|e| GpgError::Failed(e.to_string()))?;
        let _ = writer.join();
        if out.status.success() { Ok(out.stdout) }
        else { Err(GpgError::Failed(String::from_utf8_lossy(&out.stderr).into_owned())) }
    }
    // decrypt(path, pass): self.command() + ["--decrypt", path]; write only "pass\n" to stdin.
    // Exit status 2 with stderr containing "Bad session key" or "decryption failed"
    // => WrongPassphrase. Other failures => Failed(stderr).
}
```
If the encrypt round-trip test shows that gpg does not read the data after
the passphrase line on this gpg version, STOP and record it. The fallback
(--passphrase-fd 3 through an extra pipe, using the command-fds crate)
changes the spec's mandated flag and needs the owner's approval.

Notes:
  - Zero-overwrite before unlink does not guarantee erasure on SSDs or
    copy-on-write filesystems (btrfs). Say so in the README. Do not claim
    "secure deletion".
  - Hold the passphrase only in AppState (Rust). The frontend sends it
    once and never stores it in zustand or logs it. Clear the input
    fields when the modal closes.
  - Never pass the passphrase in argv or in an environment variable (both
    are visible in /proc).

 8. GLOBAL QUALITY RULES (apply in every stage)

  - Never block the UI or IPC thread with I/O. Rust file, gpg and process
    work runs in spawn_blocking or a std thread. The frontend awaits
    commands and never busy-waits.
  - Always dispose of what you create: xterm instances, addons, event
    unlisten functions, ResizeObservers, timers, debouncers, window event
    listeners and PTY sessions. Each useEffect that subscribes returns a
    cleanup.
  - Every child process goes through env_sanitize (grep for
    "Command::new" and "CommandBuilder::new". Each hit must be followed by
    a sanitize_* call). This is checked in every stage's handoff.
  - All user-visible strings live in src/lib/strings.ts. No literal UI
    text in components (aria-labels included).
  - Theme: colors come only from the CSS variables in index.css. No
    hard-coded hex in components (the terminal theme is the exception and
    is computed in lib/colors.ts).
  - Logging: Rust uses log::{debug,info,warn,error}. TS uses src/lib/log.ts.
    No println!, eprintln! or console.log (ESLint no-console = error).
    Never log passwords, passphrases, Host objects or raw PTY data at info
    level.
  - Lint: eslint --max-warnings 0; clippy -D warnings; tsc strict with
    noUncheckedIndexedAccess. Do not disable a rule inline without a
    comment giving the reason.
  - Error messages are user-friendly and actionable. They say what failed,
    the path or host involved, and what to do ("Check the permissions of
    ~/.ssh/config").
  - Every interactive element has a stable data-testid (kebab-case,
    e.g. "editor-save").
  - The owner's real files are off-limits (rule 10). Tests use temp dirs.
    Manual runs use tools/dev-sandbox.sh.
  - Commit at the end of every stage: "Stage NN: <title>".
  - Keep files under 300 lines. Split by responsibility, not
    alphabetically.

================================================================================
 10. TESTING WORKFLOW (end of every stage from Stage 0B on)
================================================================================

1.  Start the test target.
         docker start fastssh-sshd 2>/dev/null || docker run -d --name fastssh-sshd -p 127.0.0.1:2222:22 fastssh-test-sshd
         docker ps --filter name=fastssh-sshd --format '{{.Status}}'    (must say "Up")
    Refresh the fixtures without wiping the state (only use --reset when a
    stage asks for a clean slate):
         bash tools/make_fixtures.sh
    Load a fixture set into the sandbox config when a stage needs one:
         cp ~/fastssh-testenv/legacy/*.json ~/fastssh-testenv/config/
2.  Build and run while preserving the app data. The sandbox config dir
    persists between runs. Never delete it between runs of one stage.
         npm run tauri build -- --debug --no-bundle
         ./tools/dev-sandbox.sh debug > /tmp/fastssh-run.log 2>&1 &
         sleep 5; pgrep -af 'target/debug/fastssh'     (must show one process)
    Use `./tools/dev-sandbox.sh dev` for hot-reload work. The final checks
    of a stage always use the built debug binary.
3.  Permissions. Linux has no runtime prompts, so test the permission-like
    flows once per relevant stage, with real OS behaviour:
         chmod 500 ~/fastssh-testenv/config     (saving must show an error toast)
         chmod 700 ~/fastssh-testenv/config     (restore)
    The Tauri capability system is the other "permission" layer. After
    each run, check the log for "not allowed":
         grep -i 'not allowed' ~/.local/share/io.github.fastssh.app/logs/*.log
4.  Launch checks: one window titled FastSSH, no errors in the log.
         grep -iE 'error|panic' /tmp/fastssh-run.log | head
5.  Screenshots go into docs/screenshots/stage_<NN>/. LOOK at each one
    with the image-reading tool, and describe in the handoff what you see.
         mkdir -p docs/screenshots/stage_NN
         tools/screenshot.sh docs/screenshots/stage_NN/<name>.png window   (active window)
         tools/screenshot.sh docs/screenshots/stage_NN/<name>.png full     (whole screen, e.g. file manager)
    In e2e: `await browser.saveScreenshot('docs/screenshots/stage_NN/x.png')`
    (webview only; works on every desktop). Window mode captures the active
    window, so bring FastSSH to the front first (click it in e2e, or wait
    1 s after launch). If screenshot.sh exits 2, use the e2e screenshot.
6.  Drive the UI with WebdriverIO specs (npm run e2e). Find elements by
    data-testid with $('[data-testid="landing-connect"]'). Use keys:
         await browser.keys(['Control', 'Shift', 't'])
    For a double-click: (await $(sel)).doubleClick(). For right-click:
    .click({ button: 'right' }). Never click by pixel coordinates. If
    e2e can't run, do the step by hand in the sandbox and record "manual"
    plus a screenshot for each acceptance bullet.
7.  Window states (this desktop's equivalent of rotation): minimum size,
    maximized, fullscreen (F11) and back. Screenshot each, and check that
    nothing is clipped and the terminal refits (tput cols).
8.  Persistence test via force-stop and relaunch:
         pkill -TERM -f 'target/debug/fastssh'   (graceful: close handlers run)
         pkill -KILL -f 'target/debug/fastssh'   (crash: data must still be valid JSON)
         python3 -I -m json.tool ~/fastssh-testenv/config/settings.json > /dev/null && echo VALID
    Relaunch and confirm that the stage's persisted state is back.
9.  Logs on a crash or a misbehaviour:
         tail -n 200 ~/.local/share/io.github.fastssh.app/logs/*.log | grep -vE 'DEBUG'
         grep -nE 'panicked|ERROR|not allowed|symbol lookup' /tmp/fastssh-run.log
    For WebKit or rendering issues, rerun with WEBKIT_DEBUG=all and check
    stderr.
    Check child processes: `ps -o pid,args --ppid $(pgrep -f target/debug/fastssh)`.
10. Fallback input paths. The GTK/KDE file dialog (identity file, hosts
    folder) can't be driven by WebDriver. Type the path into the text
    field in tests. Open the real dialog once per stage that uses it, and
    take a screenshot proving that it opened. List "pick a file in the
    real dialog" under "Check on a real device" for the human.

Cannot be proven on a single machine (mark "check on a real device" in the
handoff and collect them in docs/MANUAL_CHECKS.md):
  - The desktop this machine does NOT run: on GNOME, the Dolphin/KIO sftp
    path, the KWallet prompt and KWin rendering; on KDE, the Nautilus/GVFS
    sftp path, the GNOME Keyring prompt and Mutter rendering.
  - The AppImage on clean installs of the Ubuntu releases this machine is
    not (22.04, 24.04 and newer: glibc and library bundling).
  - GPU vendors other than this machine's, with and without the DMABUF
    variable (the blank-window case is mostly NVIDIA + Wayland).
  - The session type this machine does not use (X11 or Wayland), unless
    the owner logs into one.
  - Audible bell loudness and feel; HiDPI fractional scaling, unless the
    owner enables it.
  - Picking a file in the native file dialog.
  - A real remote server with a non-bash shell prompt (zsh, fish).
